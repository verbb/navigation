# Templating

Build menus, sidebars, breadcrumbs, and custom node displays in Twig.

##### [Build a Header Menu with Dropdowns](/user-guides/templating/build-a-header-menu-with-dropdowns)

Build a header with a Shop dropdown and separate About and Contact links.

##### [Build a Section Sidebar with Context API](/user-guides/templating/build-a-section-sidebar-with-context-api)

Content-heavy sites often show a sidebar listing sibling pages in the current section — every page under **Products**, for example, with the current page highlighted.

##### [Build a Mega Menu](/user-guides/templating/build-a-mega-menu)

A mega menu groups links into columns and can place a promotional image beside them.

##### [Breadcrumbs: URL Trail vs Menu Trail](/user-guides/templating/breadcrumbs-url-trail-vs-menu-trail)

Breadcrumbs answer “where am I?” — but the right answer depends on whether you mean **URL structure** or **position in the menu tree**.

##### [Auto-List a Section with Dynamic Nodes](/user-guides/templating/auto-list-a-section-with-dynamic-nodes)

Use a Dynamic node to keep a list of blog posts up to date as you publish content.

##### [Node Custom Fields for Icons and Badges](/user-guides/templating/node-custom-fields-for-icons-and-badges)

Some designs attach metadata to individual links — icon classes, badge text, short descriptions — without hard-coding handles in Twig.
